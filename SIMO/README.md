# Mohammed Ziadi Barber Website — v4

Responsive one-page barber website inspired by the supplied mobile reference.

## Run locally

Open `index.html` directly, or run a local server:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Verified functionality

- Bottom navigation: Home, Services, Gallery, and Reviews
- Repeated Home taps always return to the top
- Active navigation state updates while scrolling
- Phone, WhatsApp, email, Instagram, and map links
- Downloadable vCard contact
- Validated booking form with native mobile date picker and 30-minute time slots
- Booking modal close button, backdrop close, and Escape close
- Responsive services, gallery, reviews, and fixed navigation
- Gallery lightbox
- Updated service-worker cache (`v4`) to prevent stale files
